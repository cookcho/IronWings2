# IRON WINGS II

로그라이트 종스크롤 비행 슈팅. 스테이지마다 강화 카드를 골라 기체를 키웁니다. 브라우저에서 바로 돌아가고, 폰에 설치하면 인터넷 없이도 실행됩니다.

**플레이: https://cookcho.github.io/IronWings2/**

## 조작

| | |
|---|---|
| 이동 | 화면을 끌기 |
| 사격 | 자동 |
| 폭탄 | 화면 더블탭 · 우하단 버튼 · 스페이스바 |

## 폰에 설치하기

크롬에서 위 주소를 열고 메뉴 → **앱 설치**(또는 홈 화면에 추가). 설치하면 전체 화면으로 뜨고 오프라인에서도 켜집니다.

## 구성

정적 파일만 씁니다. 빌드 과정이 없습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 — 그래픽·소리·로직이 한 파일에 들어 있습니다 |
| `sw.js` | 서비스워커. 오프라인 실행과 자동 갱신을 맡습니다 |
| `manifest.webmanifest` | 앱 이름·아이콘·화면 방향 |
| `icon-*.png` | 홈 화면 아이콘 3종 |

## 갱신

HTML을 **네트워크 우선**으로 가져옵니다. 인터넷이 되면 새 버전을 먼저 확인하고, 2.5초 안에 못 받으면 그때만 캐시를 씁니다.

그래서 **앱을 껐다 켜면 최신판이 올라옵니다.** 재설치할 필요가 없습니다.

다만 **아이콘이 바뀐 경우는 재설치해야** 합니다. 안드로이드가 아이콘을 따로 캐시하기 때문입니다.

버전은 게임 화면 왼쪽 아래에 작게 표시됩니다.
